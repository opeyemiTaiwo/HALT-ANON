\section{Methodology}
\label{sec:method}

\subsection{Task and corpus}
\label{sec:task}
\label{sec:corpus}

An instance is a triple $(v, m, \tau)$: a surveillance video $v$, a source LLM
$m$, and a prompting strategy $\tau$. The source LLM produces a free-form
forensic report $r$ describing what occurs in $v$, and each report carries an
expert reference annotation $g_v$ written independently of any model. The task
is to predict, from $r$ and optionally $g_v$, six binary labels: H1 scene
fabrication, H5 entity fabrication and H6 phantom actors, which invent content
absent from the footage; H3 crime missed, which drops the criminal act; and H2
crime misclassification and H4 severity minimization, which misstate its nature
or gravity. These group onto three axes, \emph{fabrication}, \emph{omission}
and \emph{distortion}. We report per-type AUC and $F_1$, a macro over the six,
a macro restricted to the reliable types (Section~\ref{sec:labels}), and a
binary any-hallucination score.

\paragraph{Provenance.} The reports, taxonomy, panel protocol, and
human-validation subset were introduced by prior work \citep{priorwork2026} to
measure hallucination prevalence. \textsc{halt} reuses them as raw material;
new here are the detection task, the reliability tiering, the four splits, the
baselines, and every analysis in Section~\ref{sec:results}.

The corpus draws 807 anomalous surveillance videos from UCF-Crime
\citep{sultani2018real} across eleven crime categories, paired with the
fine-grained annotations of UCA \citep{yuan2024towards} as reference. Three
frontier multimodal LLMs each analyse every video under eight prompting
strategies (zero-shot, chain-of-thought, meta-prompting, self-consistency,
sequential, ReAct, least-to-most, and iterative refinement), yielding
$19{,}361$ reports totalling $21.77$M words. Two properties distinguish this
from existing hallucination benchmarks: the outputs are long-form, averaging
$1{,}124$ words, and the corpus is fully crossed, so any comparison across
source LLMs holds the input fixed by construction. Verbosity nonetheless varies
by a factor of three under an identical task (Table~\ref{tab:corpus}), which is
the regularity Section~\ref{sec:results} shows detectors exploiting.

\subsection{Labels and their reliability}
\label{sec:labels}
\label{sec:protocol}
\label{sec:reliability}

Labels come from a panel of the same three models acting as judges
\citep{zheng2023judging}. Each report is scored by the two judges other than
the model that produced it, so no model evaluates its own output and
self-preference bias \citep{panickssery2024llm} is structurally excluded. This
yields $38{,}722$ verdicts, two per report, with zero self-judging rows, both
verifiable from the released per-judge file. The released label is the
two-judge majority with ties broken toward no hallucination, which with two
judges is a conjunction; we release the per-judge verdicts as well, so
alternative aggregation rules can be applied without rerunning any model. Judge
inputs truncate the reference to $1{,}500$ and the model output to $3{,}000$
characters, and we release the pre-truncation length of every report so this
can be conditioned on. A small number of cells carry a failure sentinel rather
than a verdict; these are excluded from the vote and flagged.

Two human annotators independently scored a stratified subset of 130 reports
spanning all source LLMs and strategies, working from the reference annotation
and the report text with the panel's labels hidden. For each type we compute
agreement between the raters, and between the panel and the rater consensus,
restricting the latter to reports where the raters agree. From these we assign
each type a reliability tier and exclude the low tier from the headline macro.
The tiers and what they imply for reading absolute rates are reported in
Section~\ref{sec:corpusstats} and released with the resource.

\subsection{Evaluation setup}
\label{sec:splits}
\label{sec:baselines}
\label{sec:release}

\begin{figure}[t]
\centering
\includegraphics[width=0.72\textwidth]{fig0_splits}
\caption{The corpus is fully crossed, so the same 19{,}361 reports admit
several disjoint partitions. Each cell is one report; rows are source LLMs and
columns are video-by-strategy conditions. (a) The standard split withholds
videos, leaving every source LLM represented in training. (b) Withholding a
source LLM asks whether a detector transfers to a model family it has never
seen, which a standard split cannot test because the source LLMs at test time
are the source LLMs at training time. (c) Withholding the multi-turn
strategies tests transfer across prompting regimes. Existing hallucination
benchmarks admit only (a).}
\label{fig:splits}
\end{figure}

Each video contributes 24 reports, so a split over reports would place the same
video in training and test and let a detector memorise the video rather than
learn the phenomenon. All splits are therefore video-disjoint
(Figure~\ref{fig:splits}). The \textbf{standard} split is crime-stratified
$70/15/15$ over videos. The \textbf{held-out source LLM} split trains on two
source LLMs and tests on the third; we report all three folds, since a single
fold confounds the difficulty of the held-out model with the transfer question.
The \textbf{held-out strategy} split trains on the four single-turn strategies
and tests on the four multi-turn ones. The \textbf{gold subset} of 130
human-annotated reports is flagged in the release as a small high-confidence
evaluation set. The held-out-source condition is the diagnostic one: existing
benchmarks draw from a single source LLM or pool several without controlling
the split, so a detector can score well by recognising who wrote a report.

We provide five reference detectors, all logistic regression with balanced
class weights, deliberately simple so that difficulty is attributable to the
task rather than to under-tuned models. \textbf{Surface} uses verbosity,
sentence statistics, hedging density, numeric detail density, type-token ratio,
truncation length, and source and strategy identity indicators;
\textbf{surface-noid} drops the identity features; \textbf{tfidf} uses word
1--2 gram TF-IDF; \textbf{embed} uses sentence embeddings; and
\textbf{grounded} uses report-versus-reference features only, namely the rate
of report tokens absent from the reference, the rate of reference tokens absent
from the report, Jaccard overlap, reference coverage, length ratio, and TF-IDF
cosine. Identity features are dropped automatically on any split where they are
constant in training and unseen at test.

We release \textsc{halt}: the corpus with reference annotations, the per-judge
verdicts, the aggregated labels, the judge and rater rubrics, the reliability
tiers with supporting $n$, the splits, reference implementations of every
baseline, the extended result tables cited in Section~\ref{sec:results}, and a
datasheet \citep{gebru2021datasheets}. The artifact is available at
\url{https://anonymous.4open.science/r/HALT-ANON-7FF2/}.
